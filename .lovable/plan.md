# Responsive design for every screen size

## How we will work (per your request)

- **Page by page.** One page at a time, never batch changes across pages.
- **You approve before each page changes.** For each page I will:
  1. Audit it at four widths — phone (390px), tablet (768px), laptop (1280px), large desktop (1920px) — plus a short-landscape phone (844×390).
  2. Send you a short list of exactly what I propose to change on that page and why.
  3. Make the changes only after you say yes.
  4. Verify the fixed page at all four widths and show you the result before moving on.
- All screen sizes have equal priority — no trade-off toward phone or desktop.

## What the audit looks for

- Text overlapping, clipping, or wrapping badly at narrow widths
- Images cropping or stretching when they should not
- Cards, grids and two-column rows that collapse awkwardly (using the grid + min-w-0 + shrink-0 pattern for mixed text/widget rows)
- Fixed pixel offsets (like the login/register card nudges) that only work at one width
- Sections with fixed heights that overflow on short screens
- Horizontal scroll / sideways overflow on phones

## Rules for the changes

- Keep the exact current look at desktop widths — responsiveness is added, the design is not restyled.
- Keep all brand colors, fonts, wording and section order unchanged.
- Only the page being worked on is touched, plus shared chrome on step 1.

A `roadmap.md` task list at the project root tracks which pages are done, in progress, and awaiting your approval, so we always know where we are.
